# 02. Recommended Browser Extensions

These browser extensions streamline competitive programming contests, automatically parse problem test cases into your editor, track your coding statistics, and improve web development workflows. They are compatible with Chromium-based browsers (Google Chrome, Brave, Microsoft Edge, Arc) and Mozilla Firefox.

---

## 1. Competitive Programming Extensions

### 1.1 Competitive Companion (Essential)

**Competitive Companion** parses competitive programming problem statements and test cases directly from websites (Codeforces, CodeChef, AtCoder, CSES, HackerRank, LeetCode, etc.) and transmits them straight into your code editor (like VS Code with the *CPH* extension) with a single click.

- **Chrome / Brave / Edge / Arc**: [Chrome Web Store Link](https://chromewebstore.google.com/detail/cjnmckjndlpiamhfimnnjmnckgghkjbl)
- **Mozilla Firefox**: [Firefox Add-ons Link](https://addons.mozilla.org/en-US/firefox/addon/competitive-companion/)

![Competitive Companion Extension](../images/Pasted%20image%2020260904112851.png)

> [!TIP]
> Once installed, you will see a green plus icon in your browser toolbar when viewing any problem on Codeforces or CodeChef. Clicking it immediately sends the sample inputs/outputs to your local VS Code!

---

### 1.2 Carrot (Rating Predictor for Codeforces)

**Carrot** calculates predicted rating changes in real-time during live Codeforces contests and updates them dynamically as submissions are made.

- **Chrome / Brave / Edge / Arc**: [Chrome Web Store Link](https://chromewebstore.google.com/detail/gakohpplicjdhhfllilcjpfildodfnnn)

![Carrot Extension](../images/Pasted%20image%2020260904113458.png)

---

### 1.3 Additional Helpful CP Extensions

- **Codeforces Rating-Based Heatmap**: Visualizes solved problems on Codeforces profiles colored by problem difficulty tag.
  - [Chrome Web Store](https://chromewebstore.google.com/detail/codeforces-rating-based-h/heajdhmohlobjebkgkpdomkaihaghkgb?hl=en)
- **Codeforces Friends Tracker**: Keeps a quick-access sidebar of your friends' active submissions and contest standings.
  - [Chrome Web Store](https://chromewebstore.google.com/detail/codeforces-friends-tracke/gfdmmpimafkhcdekeddfeifcmcjbadam)
- **CF Analytics**: Detailed breakdown of submission tags, problem verdicts, and submission time patterns on Codeforces.
  - [Chrome Web Store](https://chromewebstore.google.com/detail/cf-analytics/hhljbjodjdbjbggddjaidojnlmaobcpo)

## 2. Web Development Extensions

### 2.1 JSON Formatter / JSON Viewer

When testing REST APIs, backend endpoints, or viewing JSON responses in your browser, the default browser output is unformatted, single-line text. A JSON formatter automatically formats, color-codes, and makes JSON trees collapsible.

- **JSON Formatter**: [Chrome Web Store Link](https://chromewebstore.google.com/detail/bcjindcccaagfpapjjmafapmmgkkhgoa)
- **JSON Viewer**: [Chrome Web Store Link](https://chromewebstore.google.com/detail/aimiinbnnkboelefkjlenlgimcabobli)

---

### 2.2 React Developer Tools (Recommended for Frontend Dev)

Allows you to inspect the React component hierarchy, inspect props, state, and hooks in the Chrome DevTools tab.

- **Chrome / Brave / Edge / Arc**: [Chrome Web Store Link](https://chromewebstore.google.com/detail/fmkadmapgofadopljbjfkapdkoienihi)
- **Mozilla Firefox**: [Firefox Add-ons Link](https://addons.mozilla.org/en-US/firefox/addon/react-devtools/)
