# Universal Setup Guide (All Operating Systems)

Welcome to the Universal section of your developer setup! 

The tools, platforms, and configurations in this directory are **platform-independent**. Whether you are using Windows, macOS, or Linux, these steps are performed inside your web browser and code editor.

---

Complete the following sections in order before moving to your operating-system-specific installation:

---

## 💡 Why Universal First?

1. **GitHub is needed immediately**: In the OS sections, you will generate an SSH key on your machine and add it to your GitHub profile. Having your GitHub account created first makes this seamless.
2. **Competitive Programming Integration**: The *Competitive Companion* browser extension directly talks to the *Competitive Programming Helper (cph)* extension in VS Code. Having them configured early allows you to verify your local compiler setups immediately after installing them.
3. **Machine Learning & Data Science Access**: Platforms like Kaggle and Hugging Face provide datasets, free GPU resources (T4/P100), pre-trained models, and API tokens used across modern AI coursework.
