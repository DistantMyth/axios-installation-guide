# Free and Open Source Software (FOSS) Wing

Welcome to the **FOSS Wing** of Axios (Technical Club of IIIT Lucknow).

The FOSS Wing is dedicated to open-source culture, Linux, developer tooling, Git workflows, and collaborative software engineering.

---

## Guides & Documentation

### 🛠️ [Basic Installation Guide](basic_installation/README.md)
A complete, beginner-friendly setup guide for freshers and juniors:

1. 🌐 **[Universal Setup (Accounts & Extensions)](basic_installation/universal.md)** — GitHub, Codeforces, CodeChef accounts, browser extensions, and VS Code extensions.
2. 🪟 **[Windows Setup Guide](basic_installation/windows.md)** — Chocolatey, MinGW (C/C++), PATH configuration, and Git SSH setup.
3. 🍎 **[macOS Setup Guide](basic_installation/macos.md)** — Homebrew, GNU GCC setup (`<bits/stdc++.h>`), and Git SSH setup.
4. 🐧 **[Linux Setup Guide](basic_installation/linux.md)** — Ubuntu/Debian (`apt`), Arch (`pacman`), and Fedora (`dnf`) guides, PATH, and Git SSH setup.
5. ✅ **[Verification Checklist](basic_installation/checklist.md)** — Quick verification checklist and command cheat sheet.
